# EliteAlgoTrader 📈
Framework de trading algorithmique modulaire de niveau institutionnel.
- `src/strategies/` : Moteurs de signaux vectorisés (SMA, RSI, HMM).
- `src/risk/` : Gestionnaires d'exposition et filtres de conformité Bâle III.
- `src/data/` : Connecteurs de flux de prix asynchrones.
